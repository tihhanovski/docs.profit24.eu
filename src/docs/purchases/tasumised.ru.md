# Платежи

Profit позволяет экспортировать платежи в файл формата XML.

Экспортируются платежи с отметкой **Экспортировать** и **подтверждённые** платежи.

## Экспорт платежей

1. Задайте фильтр по периоду.
2. Выберите способ оплаты для экспорта.
3. Нажмите **Экспортировать**.
