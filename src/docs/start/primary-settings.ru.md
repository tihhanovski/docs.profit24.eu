# Основные настройки компании

После создания базы данных компании стоит проверить её ключевые параметры.

Открыть настройки можно с главной страницы компании, нажав значок шестерёнки справа от названия.

Также пункт **Настройки** доступен в главном меню, и у каждой компании в списке «Мои компании» есть собственная кнопка настроек.

Настройки сгруппированы по разделам:

## Настройки компании

![Настройки компании](company-setup.png)

Здесь вводятся основные реквизиты:

- наименование
- регистрационный код
- номер плательщика НДС
- адрес
- телефон
- email
- базовая валюта
- базовый прайс-лист
- страна
- вводятся ли цены с НДС по умолчанию

Значения сохраняются автоматически при выходе из поля.

## Продажи

Параметры, связанные с продажами, например:

- правила округления сумм на счётах.

## Формы печати

Настройка шаблонов счетов, заказов и предложений:

- выбор и расположение логотипа
- вывод реквизитов клиента
- настройки отображения товарных строк
- дополнительные тексты и значения по умолчанию
- информация в подвале и т.д.

## Компании

Значения по умолчанию для справочника клиентов/поставщиков:

- срок оплаты
- счёт клиента и поставщика

## E‑арвe (электронные счета)

Параметры отправки и получения e‑арве.

## Кассa/чеки

Настройка распознавания чеков и импортированных счетов:

- включение функции
- распознавание строк
- **Использовать очередь** — при включении загруженные чеки ставятся в очередь, и AI‑ассистент обрабатывает их асинхронно; не нужно ждать завершения
- Тег для импортированного счёта — помогает отличить импорт
- Товар по умолчанию — используется, когда строки объединяются; можно задавать по поставщику

## Склад

Настройка автоматического создания расходных/приходных накладных.

## Пакеты и модули

Выбор тарифного пакета и подключённых модулей.

## Пользователи

Администратор компании добавляет и удаляет пользователей.

Чтобы пригласить пользователя, нужен его ник (см. [выбор имени пользователя](register.ru.md#выбор-имени-пользователя)) или email. Если у человека ещё нет аккаунта, ему придёт приглашение.

## Опасные настройки

Удаление базы и передача владения.

Удалённую базу можно восстановить в течение нескольких дней, обратившись к консультанту (услуга платная); после этого срока данные удаляются полностью.

После передачи владения прежний владелец больше не может управлять пользователями или удалять базу. Процедура необратима — чтобы вернуть доступ, нужно договориться с новым владельцем.

## Контроль данных

Указывается, какие автоматические проверки данных выполняются.

## Обновление базы данных

При необходимости администратор может запустить проверку/исправление структуры базы. Обычно это не требуется: Profit автоматически выполняет обслуживание раз в сутки.
