# Начало работы с Profit

Следуйте этим простым шагам, чтобы быстро запустить Profit:

- [Зарегистрируйте пользователя](register.ru.md)

    Регистрация в Profit бесплатная. Мы даже зачислим немного средств на ваш счет, чтобы вы могли спокойно изучить систему и начать реальную работу без обязательств.

- [Выберите имя пользователя](register.ru.md#выбор-имени-пользователя)
- [Создайте базу данных компании](create-db.ru.md) или [получите доступ к существующей](access-other-company.ru.md)
- [Заполните ключевые настройки компании](primary-settings.md)
- [Настройте свой профиль пользователя](user-settings.md)

Готово! Теперь вы можете оформлять счета, вводить покупки, вести склад и многое другое.
