# Сопутствующие товары

Некоторые товары могут **притягивать за собой дополнительные товары**: когда основной товар используется в строке документа, эти дополнительные товары добавляются автоматически. Типичные примеры – комплекты, залоги (депозиты), части набора или другие товары, которые необходимо поставлять вместе с основным.

!!! note "Включение функции"
    Функция является глобальной настройкой, которую можно включить или отключить в настройках компании. Если она отключена, строки автоматически не добавляются.

## Где работает функция

Сопутствующие товары работают в документах продажи, покупки и склада:

- счета продажи;
- коммерческие предложения;
- заказы продажи;
- счета покупки;
- накладные и приходы на склад.

## Как это выглядит для пользователя

1. Выберите товар в строке документа (или измените уже введённый).
2. Если у этого товара заданы сопутствующие товары, программа добавляет соответствующие строки **после** основной строки.
3. **Количество** добавленной строки рассчитывается по формуле: **количество основной строки × количество сопутствующего товара**.
4. Автоматически добавленные строки – обычные строки, при необходимости их можно изменить (например, цену, стоимость).

## Изменения вручную

- При изменении количества основной строки программа пересчитывает сопутствующие строки, но **введённые вами вручную значения сохраняются** – они возвращаются в пересчитанную строку.
- Изменение основной строки автоматически обновляет только те поля, которые должны следовать за основной строкой (например, количество).
- Если вы сами изменили **количество** добавленной строки, программа больше не перезаписывает его автоматически.

## Удаление основной строки

При удалении основной строки вместе с ней удаляются и строки, автоматически добавленные через неё.
