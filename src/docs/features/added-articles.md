# Kaasaskäivad artiklid

Osa kaupu võib endaga **kaasa tuua täiendavaid artikleid**, mis lisatakse dokumendireale automaatselt, kui põhiartiklit real kasutatakse. Tüüpilised näited on paketid, tagatisrahad, komplekti kuuluvad osad või muud kohustuslikult kaasatoodavad kaubad.

!!! note "Sisselülitamine"
    Funktsioon on ettevõtte seadistustes lülitatav globaalne seade. Kui see on välja lülitatud, automaatseid ridu ei lisata.

## Kus funktsioon töötab

Kaasaskäivad artiklid toimivad nii müügi- kui ka ostu- ja laodokumentidel:

- müügiarved;
- müügipakkumised;
- müügitellimused;
- ostuarved;
- saatelehed ja lao sissetulekud.

## Kuidas see avaldub

1. Vali dokumendi real artikkel (või muuda olemasolevat).
2. Kui sellel artiklil on määratud kaasaskäivad artiklid, lisab programm põhirea **järele** automaatselt vastavad read.
3. Genereeritud rea **kogus** arvutatakse põhirea kogusest: **põhirea kogus × kaasaskäiva artikli kogus**.
4. Automaatselt lisatud read on tavalised read – neid saab vajadusel muuta (nt hind, kulu).

## Muudatused koostamise ajal

- Kui muudad põhirea kogust, uuendatakse kaasaskäivate ridade kogused vastavalt.
- Käsitsi sisestatud väärtused (nt kulu või hind) jäävad muudatuste käigus alles.
- Kui oled genereeritud rea kogust ise muutnud, ei kirjuta programm seda enam automaatselt üle.

## Põhirea eemaldamine

Põhirea eemaldamisel kaasaskäivaid ridu **ei kustutata** – neist saavad iseseisvad tavalised read, mida saab eraldi muuta või kustutada.

## Kaasaskäivate artiklite määramine

Kaasaskäivad artiklid määratakse artikli seoste (linkide) hulgas, kus seose tüübiks on **Kaasaskäiv artikkel**.

!!! note "Seose kehtivus"
    Seos põhirea ja selle kaudu automaatselt lisatud ridade vahel kehtib dokumendi **koostamise ajal**. Dokumendi salvestamisel muutuvad genereeritud read tavalisteks ridadeks.
