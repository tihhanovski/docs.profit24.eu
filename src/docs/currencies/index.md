# Valuutad

Profit laeb valuutakursid automaatselt Euroopa Keskpangast.

## Kasutamine

Erinevaid valuutasid saab kasutada pea kõigil dokumentidel:

- Müügiarved, -pakkumised, -tellimused
- Ostuarved
- Laekumised ja tasumised

Eurost erinevas valuutas dokumentide kanded tehakse dokumendi valuutas ja baasvaluutasse (eurodesse) konverteerituna dokumendile/kandele märgitud kursiga ja finantsaruandeid saab võtta nii valuutades kui eurodes.

Loe lisaks [data.ecb.europa.eu](https://data.ecb.europa.eu/help/api/data).
