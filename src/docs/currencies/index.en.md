# Currencies

Profit automatically loads exchange rates from the European Central Bank.

## Usage

Different currencies can be used on most documents:

- Sales invoices, quotes, orders
- Purchase invoices, orders
- Receipts and payments

Entries in non-EUR currencies are posted in the document currency and converted to the base currency (euro) using the exchange rate specified on the document. Financial reports can be viewed in both the original currency and euros.

See also [data.ecb.europa.eu](https://data.ecb.europa.eu/help/api/data).
