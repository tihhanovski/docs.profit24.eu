# Profit version history

The latest version of Profit is available online at [app.profit24.eu](https://app.profit24.eu).

If you want to test the next version of Profit, you can use [testapp.profit24.eu](https://testapp.profit24.eu).

We thoroughly test Profit before releasing updates, but if you find something broken after an update and need a quick workaround, you can try the previous user interface at [old.intellisoft.ee](https://old.intellisoft.ee).
