# История версий

Последняя версия Profit доступна онлайн по адресу [app.profit24.eu](https://app.profit24.eu).

Если вы хотите протестировать следующую версию Profit, вы можете перейти по адресу [testapp.profit24.eu](https://testapp.profit24.eu).

Мы тщательно тестируем Profit перед выпуском обновлений, но если вы обнаружили, что после обновления что-то не работает и нужно быстро найти решение, вы можете попробовать предыдущую версию пользовательского интерфейса: [old.profit24.eu](https://old.profit24.eu)

Выберите версию слева, чтобы ознакомиться с информацией о ней.
