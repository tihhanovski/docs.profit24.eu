# 0.66 30.09.2026

- Функциональность сопутствующих товаров
    - Для товара можно задать сопутствующие товары, которые автоматически добавляются в строку документа при использовании основного товара в строке (например, комплекты, залоги, части набора)
    - Количество добавленной строки = количество основной строки × количество сопутствующего товара; автоматически добавленные строки можно при необходимости изменить
    - Работает в документах продажи, покупки и склада. Подробнее: [Сопутствующие товары](../features/added-articles.md)
