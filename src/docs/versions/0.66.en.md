# 0.66 30.09.2026

- Added articles feature
    - An article can have accompanying articles defined that are added to the document row automatically when the parent article is used on the row (e.g. packages, deposits, parts belonging to a set)
    - Generated row quantity = parent row quantity × added article quantity; automatically added rows can be edited if needed
    - Works on sales, purchase and warehouse documents. Read more: [Added articles](../features/added-articles.md)
