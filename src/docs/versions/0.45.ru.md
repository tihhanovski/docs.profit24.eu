# 0.45 21.10.2025

Версия 0.45 включает множество как видимых, так и внутренних улучшений:

- Добавлена первая версия интерфейса реестра коммерческих предложений
- Обновлена панель навигации
- [Добавлена тёмная цветовая схема](../ui/colorscheme.md)
- Обновлены переводы интерфейса
- Уточнены документы «Условия использования» и «Политика конфиденциальности»
- Крупное обновление компонентов — быстрее, надёжнее, удобнее
- Множество других небольших улучшений интерфейса
- Новые фильтры в реестре счетов на покупку
    - фильтр неподтверждённых счетов
    - период создания
    - период изменения
    - период даты расхода
- Новые фильтры в реестре счетов на продажу
    - фильтр неподтверждённых счетов
    - период создания
    - период изменения

- Добавлены модули финансов, склада и основных средств
