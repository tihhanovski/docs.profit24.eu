# 0.66 30.09.2026

- Lisatavate kaupade funktsionaalsus
    - Artiklile saab määrata kaasaskäivaid artikleid, mis lisatakse dokumendireale automaatselt, kui põhiartiklit real kasutatakse (nt paketid, tagatisrahad, komplekti kuuluvad osad)
    - Genereeritud rea kogus = põhirea kogus × kaasaskäiva artikli kogus; automaatselt lisatud ridu saab vajadusel muuta
    - Toimib müügi-, ostu- ja laodokumentidel. Lähemalt: [Kaasaskäivad artiklid](../features/added-articles.md)
